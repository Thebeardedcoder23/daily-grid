# Daily Grid

Private working repository for a mobile-first custom crossword.

## Project goals

- 11x11 crossword
- Monday-level difficulty
- Mobile-first solving experience
- Mix ordinary crossword fill with personalized clues
- Hidden completion reveal handled only after a correct solve
- Neutral public-facing title and repository naming
- Static site suitable for GitHub Pages

## Workflow

1. Design and validate the crossword grid.
2. Review clues and answers.
3. Build the mobile solver.
4. Add and test the completion reveal.
5. Test on phone.
6. Publish only when ready.

Personalized puzzle data and reveal behavior will be kept separate from the UI where practical so they can be revised without rebuilding the entire app.
